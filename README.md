### Задача
Пользователи должны иметь возможность:
- Видеть оптимальный макет в зависимости от размера экрана их устройства.
- Видеть состояния наведения (hover) для всех интерактивных элементов.

### Ссылка на проект
- Живой сайт (GitHub Pages): "https://honikon.github.io/social-media-profile-html-css/"

## Мой процесс
Процесс состоит из таких пунктов:
- Создать сам контейнер, в котором распалагалась вся информация из задания.
- Заняться стилистикой блоков, заголовков и т.п.
- Стуктурировать этот контейнер по центру.
- Правильно структурировать селекторы.

### Технологии
- Семантическая верстка HTML5
- CSS3 (Flexbox для центрирования)
- Mobile-first подход

### Чему я научился:
- **Структурирование стилей**: Научился правильно организовывать селекторы для поддержания чистоты кода и соблюдения иерархии.
- **Практика Flexbox**: Использовал флекс-контейнеры для идеального центрирования карточки на странице.
- **Интерактивность**: Реализовал плавную смену состояний кнопок при наведении с помощью `:hover` и `transition`.

Пример кода для интерактивных кнопок:
```css
.btn:hover {
  background-color: var(--green-color);
  color: var(--dark-grey);
  transition: 0.3s;
}
```
